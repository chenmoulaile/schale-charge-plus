# Hina (空崎日奈) Character Theme Assets

## Overview
This directory contains character-specific background assets for SCHALE Charge Plus HUD theme system.

## Files

### Default Uniform
- **background_hina.png** - Main hall scene with Sorasaki Hina in standard uniform
- Background atmosphere matching purple/pink color scheme

### Swimsuit
- **background_swimsuit.png** - Summer beach scene with light blue tones
- Matching her cyan/teal swimsuit palette

### Dress
- **background_dress.png** - Elegant evening scene
- Purple/violet atmospheric backdrop

### Nightwear  
- **background_nightwear.png** - Cozy home setting
- Warm yellow/gold lighting ambience

## Visual Features

Each Hina background includes:
- **Character Memory Scene**: In-game memory hall or official artwork scenes
- **Atmospheric Blur**: Soft focus background effect for depth
- **Color Matched Overlay**: Semi-transparent gradient tinting using her signature pink (#E448F6)
- **Scaled Parallax**: Background extends 3x beyond visible HUD area for smooth movement illusion

## Usage Notes

1. Images should be 1920x1080px resolution minimum
2. Formats: PNG preferred for quality, MP4 videos supported but larger file size
3. Transparency: Background opacity controlled per-theme (default 0.25)
4. The halo crown shape remains constant across all outfits
