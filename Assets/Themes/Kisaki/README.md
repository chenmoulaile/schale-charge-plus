# Kisaki (龙华妃咲) Character Theme Assets

## Overview  
This directory contains character-specific background assets for SCHALE Charge Plus HUD theme system.

## Files

### Default Uniform
- **background_kisaki.png** - Main hall scene with Ryuge Kisaki in standard form
- Deep indigo atmosphere matching her cyan/silver palette

### Swimsuit
- **background_swimsuit.png** - Summer vacation beach setting  
- Coral/soft pink tones complementing her swimwear

### Kindergarten
- **background_kindergarten.png** - Cute school room/campus setting
- Warm yellow/orange lighting like her signature yellow cap

## Visual Features

Each Kisaki background includes:
- **Character Memory Scene**: Game memory hall or official key art
- **Crescent Moon Halo Integration**: Background complements her cloud-scroll crescent moon design
- **Color Matched Gradient Overlay**: Semi-transparent tint using her palette (#66B4D2 cyan primary)
- **Dynamic Scaling**: Parallax effect through oversized background rendering

## Unique Design Elements

Kisaki themes feature:
- **Cloud Scroll Crescent Halo**: Unique swirling crescent shape different from Hina's crown
- **Atmospheric Depth**: Soft bokeh effects in background scenes
- **Character Expression**: Background scenes capture her distinctive personality traits
- **Outfit Consistency**: Same halo across all outfits represents her character identity
