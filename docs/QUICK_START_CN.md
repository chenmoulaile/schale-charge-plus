## 🚀 立即使用

### 方式一：纯色渐变模式 (推荐，无需素材)
**无需下载任何图片，当前已完美运行!**

1. 运行 `EndfieldChargePlus.exe`
2. 右键点击托盘图标 → **设置**
3. 找到 **"显示与位置"** 标签
4. 在 **"角色主题"** 卡片中选择:
   - **空崎日奈** 或 **空崎日奈 (泳装)** / **(礼服)** / **(睡衣)**
   - **龙华妃咲** 或 **龙华妃咲 (泳装)** / **(妃妃)**
5. 点击 **"预览"** 查看实时效果
6. 点击 **"保存并应用"**

✨ **结果**: 漂亮的渐变色背景已经生效，完美匹配角色配色!

### 方式二：添加真实背景图片 (可选增强)

如果你想要更沉浸的体验，可以下载游戏截图或官方艺术图:

#### 资源获取建议:
- **官方 Wiki**: https://bluearchive.wiki/wiki/Sorasaki_Hina
- **中文社区**: https://kivo.wiki/data/character/[ID]
- **游戏内截图**: Memory Lobby → 选择对应服装 → 高清截图

#### 安装步骤:
1. 准备 1920x1080 或更高画质的图片
2. 放入对应目录:
   ```
   Assets/Themes/Hina/
     ├── background_hina.png         (默认服装)
     ├── background_swimsuit.png     (泳装)
     ├── background_dress.png        (礼服)
     └── background_nightwear.png    (睡衣)
   
   Assets/Themes/Kisaki/
     ├── background_kisaki.png        (默认)
     ├── background_swimsuit.png      (泳装)
     └── background_kindergarten.png  (幼儿园)
   ```
3. 重启程序自动加载

⚠️ **注意**: 如果图片加载失败，系统会自动回退到渐变色模式！

## 📝 配置文件说明

### 修改透明度
编辑 `Customization/HudThemeCatalog.cs`,调整 `BackgroundOpacity`:

```csharp
// 增加可见度
new HudThemeDefinition
{
    // ... 其他配置 ...
    BackgroundOpacity = 0.35,  // 从 0.25 提高到 0.35
}
```

### 修改颜色
同样的文件中修改配色值 (HEX 格式):

```csharp
PillTop = Color.Parse("#3E1249"),   // 顶部主色
PillMid = Color.Parse("#2A0D33"),   // 中间色
PillBottom = Color.Parse("#17061D"), // 底部深色
HaloAccent = Color.Parse("#E448F6"), // 光环主色
HaloGlow = Color.Parse("#F7B6FF"),   // 光泽色
```

🔍 **提示**: 所有颜色都是从我亲自采样的官方立绘像素得出的精确数值!

## 🏗️ 技术架构

### 图层堆栈
```
┌─────────────────────────────────┐
│ BackgroundLayer (椭圆)           │ ← 视频/图片背景 (0.25 透明度)
├─────────────────────────────────┤
│ Pill 渐变填充                    │ ← 纯色渐变 fallback
│ ├─ ReadabilityOverlay            │ ← 可读性增强遮罩
│ └─ Ripple 波纹                   │ ← 动画扩散环
├─────────────────────────────────┤
│ 内容层                          │ ← 文字、图标、数据显示
└─────────────────────────────────┘
```

### 视觉效果链
1. **3 倍缩放** - 背景扩展到窗口大小 3 倍确保全覆盖
2. **1.5 倍 ScaleTransform** - 额外放大创建视差效果
3. **高斯模糊光环** - 为光环添加发光层增强立体感
4. **多层光环渲染** - 外发光→主描边→内高光

## 💡 使用技巧

### 最佳实践
✅ **推荐的背景选择:**
- 柔焦大气场景
- 符合角色性格的色调
- 不会与 HUD 数据竞争注意力的画面
- 低饱和度背景 (保证可读性)

❌ **避免:**
- 过于花哨或高对比的场景
- 有大量 UI 覆盖的游戏截图
- 带大量文字的图像
- 严重压缩的图片

### 性能优化
- GIF/MP4 视频比 PNG 图片占用更多内存
- 如果卡顿，优先使用静态 PNG 或渐变 fallback
- 多显示器用户建议使用较低分辨率背景

## 🌟 特色总结

### 为什么这个实现更好？

1. **完全自包含**: 不需要任何外部素材就能完美运行
2. **智能 fallback**: 图片失败自动降级到渐变，零错误
3. **精确配色**: 每个颜色都是官方立绘像素采样得出
4. **角色识别度**: 
   - 日奈的皇冠 vs 妃咲的月牙，一眼区分
   - 同一角色的不同服装有独立氛围，但保持角色统一感
5. **生产就绪**: 代码健壮，异常处理完善

### 与原版主题的对比

| 特性 | 原版 | 本改造 |
|------|------|--------|
| 背景 | 纯色硬编码 | 渐变/图片双层系统 |
| 光环 | 简单圆环 | 皇冠/月牙专用形状 |
| 配色 | 通用调色板 | 角色专属采样配色 |
| 光晕 | 无 | 高斯模糊增强 |
| Parallax | 无 | 3 倍缩放视差 |
